initialBufferCapacity

The initial size of the read and write buffers. In practice, it's not critical to set this unless you know in advance that your messages are going to be very large. (You can pass TFramedTransportWithReusableBuffer.DEFAULT_BUF_CAPACITY if you're only using this constructor because you want to set the maxLength.)

maxLength

The max frame size you are willing to read. You can use this parameter to limit how much memory can be allocated.
